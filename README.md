# Транскрибер

Расшифровка звонков и итоги разговоров: https://transcriber.kahman.studio

Запись звонка из Заметок iPhone (или из мессенджера) загружается на сайт. Gemini делает
дословную расшифровку по говорящим и итог по шаблону («Холодный звонок», «Созвон с
заказчиком» или «Авто»), итог собирается в Word вместе с полной расшифровкой. Всё видно
в истории звонков, готовый итог приходит в Telegram.

План и требования — в [PLAN.md](PLAN.md).

## Как устроено

```
iPhone: «Поделиться» → Быстрая команда ─┐
Сайт: кнопка «Загрузить» ───────────────┤
                                         ▼
                nginx → app.main (FastAPI, вход, история, плеер)
                                         │ SQLite: очередь
                                         ▼
                app.worker → transcribe.py → summarize.py → make_docx.py
                     │                 │
                     │                 └→ Cloudflare Worker → Gemini API
                     └→ Cloudflare Worker → Telegram Bot API
```

Сервер стоит в России: Google и Telegram доступны только через свои Worker'ы на Cloudflare
(`cloudflare/`). Ключи в Worker'ах не хранятся — их передаёт сервер в каждом запросе.

| Файл | Что делает |
|---|---|
| `transcribe.py` | Режет запись на куски по 10 минут, расшифровывает в Gemini, склеивает со сквозными таймкодами. При сбое продолжает с места обрыва. |
| `summarize.py` | Итог по расшифровке, шаблоны в начале файла. |
| `make_docx.py` | Word из markdown, в конце — полная расшифровка. |
| `app/main.py` | Сайт: вход, история, загрузка, страница звонка, настройки. |
| `app/worker.py` | Очередь обработки (отдельная служба). |
| `app/security.py` | Пароль, сессии, CSRF, защита от перебора, второй фактор, токены команды. |
| `deploy/` | Установка и обновление сервера, nginx, systemd, fail2ban. |
| `cloudflare/` | Прокси для Gemini и Telegram. |
| `docs/` | Инструкции: Быстрая команда, Telegram. |

## Локально

```
python -m pip install -r requirements.txt
copy .env.example .env      # заполнить GEMINI_API_KEY, GEMINI_BASE_URL; TRANSCRIBER_DEV=1
python tools/set_password.py
python -m uvicorn app.main:app --port 8780
python -m app.worker        # во втором окне
```

Командная строка по-прежнему работает без сайта (её использует скилл `call-transcript`):

```
python transcribe.py "Голос 002.m4a" --name "Созвон" --context "Иван — заказчик"
python summarize.py "results/Созвон/транскрипция.txt" --template client
```

## Сервер

Первичная установка (один раз): `ssh root@130.49.146.66 'bash -s' < deploy/bootstrap.sh`.
Дальше пуш в `main` → GitHub Actions → `deploy/deploy.sh` обновляет сервер сам.
Для этого в репозитории нужен секрет `DEPLOY_KEY` — приватный SSH-ключ к серверу.

- Код: `/opt/transcriber`, данные (база, записи, итоги): `/var/lib/transcriber`.
- Ключи: `/etc/transcriber.env` (600, root). Образец — `.env.example`.
- Пароль: `python tools/set_password.py --server root@130.49.146.66 --key путь\к\ключу`.
- Журналы: `journalctl -u transcriber -u transcriber-worker -f`.

## Защита

- Пароль хранится только хэшем argon2id; второй фактор (TOTP) — в настройках сайта.
- Сессии: случайный токен, в базе только хэш; cookie `__Host-`, HttpOnly, Secure, SameSite.
- CSRF-токен в каждой форме + проверка Origin.
- Перебор: растущая пауза для адреса, общий лимит на все адреса, `limit_req` в nginx,
  fail2ban, сообщения в Telegram о блокировках и входах.
- Запросы к базе только с параметрами, автоэкранирование шаблонов, строгая CSP без
  встроенных скриптов, HSTS, запрет встраивания и индексации.
- Файлы: имена генерирует сервер, ffmpeg проверяет, что это звук, отдача — только после входа.
- Службы работают от отдельного пользователя, на запись доступна только папка данных.

## Что важно знать

- В поле «С кем разговор» — только имя. Если перечислить компанию, конкурентов или темы,
  модель начинает вставлять их в текст.
- Бесплатные модели иногда перегружены (503) — скрипт повторяет и переключает модели.
- На бесплатном уровне Google может использовать записи для обучения моделей.
