# Быстрая команда «В транскрибер»

Отправляет запись на сайт прямо из меню «Поделиться» — в Заметках, Telegram, «Файлах»,
«Диктофоне». Safari не умеет показывать сайты в этом меню, поэтому нужна команда.

## 1. Токен

Сайт → «Настройки» → «Быстрая команда iPhone» → «Создать токен». Скопируйте его:
он показывается один раз. Токен разрешает только загружать записи и отзывается там же.

## 2. Команда

Приложение «Быстрые команды» → «+».

1. Название (вверху): **В транскрибер**. Значок — любой.
2. Нажмите «ⓘ» (внизу) → включите **«Показывать на листе „Поделиться“»**.
   В «Типы» оставьте **Файлы** и **Медиа** (остальное можно выключить).
3. Если на экране появилось «Получать … из Поделиться», в пункте «Если нет входных данных»
   выберите «Продолжить».
4. Добавьте действие **«Запросить ввод»**:
   - тип — Текст;
   - вопрос — `С кем разговор?`;
   - «Разрешить пустой ответ» — включить (если есть в вашей версии; иначе просто вводите имя).
5. Добавьте действие **«Получить содержимое URL»**:
   - URL: `https://transcriber.kahman.studio/api/upload`;
   - нажмите «Показать больше»;
   - Метод: **POST**;
   - Заголовки → «Добавить новый заголовок»: ключ `Authorization`, значение `Bearer ` + ваш токен
     (слово Bearer, пробел, токен);
   - Тело запроса: **Форма**;
     - новое поле → **Файл**: ключ `file`, значение — переменная «Ввод из быстрой команды»;
     - новое поле → **Текст**: ключ `contact`, значение — переменная «Введённый текст».
   - Необязательно: поле **Текст** `template` со значением `cold` (холодный звонок),
     `client` (созвон с заказчиком) или `auto`.
6. Добавьте действие **«Показать уведомление»**: текст — переменная «Содержимое URL».

## 3. Как пользоваться

Заметки → запись звонка → нажмите на запись → «Поделиться» (или «…» → «Поделиться аудио»)
→ «В транскрибер» → имя собеседника → готово. Через минуту-две итог появится на сайте
и придёт в Telegram.

Если команда пишет «Неверный токен» — создайте новый в настройках и замените в заголовке.
