Команда «В транскрибер» отправляет запись из меню «Поделиться» в Заметках, Telegram и «Файлах». Для неё нужен токен: он даёт право только загружать записи.

Как собрать команду
  1. Откройте «Быстрые команды» → «+». Назовите команду «В транскрибер».
  2. Нажмите «i» внизу → включите «Показывать на листе „Поделиться“». В «Типы» оставьте «Файлы» и «Медиа».
  3. Добавьте действие «Запросить ввод»: текст, вопрос «С кем разговор?», ответ можно оставить пустым.
  4. Добавьте «Получить содержимое URL»: адрес {{ base_url }}/api/upload, метод POST.
    Заголовки: Authorization = Bearer ваш_токен.
    Тело запроса: «Форма». Поля: file — тип «Файл», значение «Ввод из быстрой команды»; contact — текст «Введённый текст».
  5. Добавьте «Показать уведомление» с результатом «Содержимое URL».

Подробная инструкция с картинками — в репозитории, docs/shortcut.md.
